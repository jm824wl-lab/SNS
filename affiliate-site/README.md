# Small Team CRM Guide(海外SaaSアフィリエイト用サイト)

米国の小規模事業者向けに、HubSpot と Pipedrive を比較する英語の静的サイトです。
同じリポジトリ内の不動産物件リスト化ツール(`backend/`・`frontend/`)とは無関係で、
このフォルダだけで完結します。独立したリポジトリへ移しても動きます。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | トップページ |
| `hubspot-vs-pipedrive.html` | 比較記事(料金表・初年度費用の計算機つき) |
| `disclosure.html` | アフィリエイト開示・調査方法・運営者・プライバシー |
| `site.js` | アフィリエイトリンクと料金データの設定 |
| `styles.css` | デザイン |
| `x-posts.md` | 英語X投稿の下書き8本(日本語訳つき) |

ビルドは不要です。ブラウザで `index.html` を開けば確認できます。

## 公開前に必ずやること

1. **料金を公式ページで確認する。** `site.js` の `PLANS` は第三者サイト経由で集めた2026年11月時点の
   定価です。HubSpot と Pipedrive の料金ページで照合し、`PRICES_CHECKED` を更新してください。
   特に次の点は情報源によって食い違いがありました。
   - Pipedrive Premium の年払い価格(59ドルと49ドルの両説)
   - HubSpot 無料プランの連絡先件数の上限(記事には書いていません)
   - HubSpot Starter の新規顧客向け割引価格
2. **運営者情報を入れる。** `disclosure.html` の `REPLACE-WITH-YOUR-EMAIL` と
   `REPLACE-WITH-YOUR-NAME-OR-BUSINESS` を置き換えてください。
3. **両製品を自分で触る。** HubSpot の無料CRMと Pipedrive の14日間トライアルを実際に使い、
   気づいた点を記事に加えてください。`disclosure.html` には「実際に試したとは主張しない」
   「編集者が公式ページと照合した」と書いてあるので、内容を事実に合わせてください。
4. **各プログラムの規約を読む。** 特に次の点です。
   - HubSpot は規約で、AI生成を含む「偽の、または不誠実なレビュー」を禁止しています。
     この記事は体験レビューではなく公開情報の比較として書いていますが、解釈は HubSpot 側が決めます。
     不安なら申請時に確認してください。
   - HubSpot は自社ブランド名での検索広告出稿を禁止しています。
   - 日本在住者の参加可否、Xでの紹介可否、日本への支払い方法は未確認です。

## 公開の手順

1. このフォルダを静的ホスティングに置く(GitHub Pages、Cloudflare Pages、Netlify など)。
   独自ドメインがあると提携審査で有利です。
2. HubSpot(impact.com 経由)と Pipedrive(PartnerStack 経由)に提携申請する。
3. 承認されたら、発行されたリンクを `site.js` の `AFFILIATE_LINKS` に入れる。
   空のままなら各社の公式ページへの通常リンクとして動きます。
4. `x-posts.md` の `[URL]` を公開URLに置き換え、まず投稿1・4・7を公開する。

## 報酬条件(2026年11月時点、要再確認)

| 案件 | 報酬 | 経由 |
|---|---|---|
| HubSpot | 30%を最大12か月 | impact.com |
| Pipedrive | 20%(上位ティア30%)を最初の12か月 | PartnerStack |

## 数字の追い方

最初の30日は、成果件数よりも次の3つを記録してください。

- X投稿ごとの表示回数とリンククリック数
- 比較記事から各社へのクリック数(各ASPの管理画面)
- 成果の状態(発生・承認待ち・承認・否認)
