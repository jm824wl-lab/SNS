# 経営コンサルティング

## 概要

経営コンサルティング案件(戦略・組織・業務改善等のクライアント向けコンサルティング)
を管理する。

## ファイル構成

- `案件一覧.csv` — クライアントごとの案件一覧。列: No, クライアント名, 紹介者, ステータス,
  開始日, 内容, 次のアクション, 備考
  (2026-11-19、`紹介者`列を追加。favy案件は誰からの紹介かメールから特定できておらず
  `不明(要確認)`としている。要確認事項として対応)

## 運用ルール

- 新しい案件を把握したら`案件一覧.csv`に行を追加する。
- ステータスが変わったら該当行を更新する(契約前/契約済み/実行中/完了等)。
- 作業ログは `コンサル部/logs/YYYY-MM-DD.md` に追記形式で記録する。
- 判断に迷う内容は `secretary/inbox/` に記録する。
