# その他

## 概要

経営コンサルティング・不動産仲介・M&A仲介のいずれにも当てはまらないコンサル部案件を
管理する。

## ファイル構成

- `案件一覧.csv` — 案件ごとの一覧。列: No, 案件名, ステータス, 開始日, 内容,
  次のアクション, 備考

## 運用ルール

- 新しい案件を把握したら`案件一覧.csv`に行を追加する。
- サービス区分の判断に迷う場合は、まずここに記録した上で`secretary/inbox/`に
  確認事項として残し、ユーザーの判断を仰ぐ。
- 作業ログは `コンサル部/logs/YYYY-MM-DD.md` に追記形式で記録する。
