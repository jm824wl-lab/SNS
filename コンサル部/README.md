# コンサル部

## 担当業務

- コンサルティング実行
- クライアント対応

## サービス区分と案件管理(2026-11-19〜)

コンサル部の案件は、以下4つのサービス区分ごとにサブフォルダで管理する。

- `経営コンサルティング/` — 経営コンサルティング案件
- `不動産仲介/` — 不動産仲介案件
- `M&A仲介/` — M&A仲介案件(紹介者・仲介者としての案件を含む)
- `その他/` — 上記に当てはまらない案件

各サブフォルダの構成・運用ルールは、それぞれの`README.md`を参照。基本的には
「案件一覧.csv(企業名/案件名・ステータス・日付・次のアクション・備考)」で
進捗を管理し、必要に応じて個別の取引先ごとにさらにサブフォルダを作る
(例: `M&A仲介/BoldInvestment案件管理/`)。

## 運用ルール

- 秘書がこのフォルダに直接作業内容を記録する。
- 作業ログは `logs/YYYY-MM-DD.md` に追記形式で記録する（同日ファイルがあれば追記）。
- 既存ファイルは上書きしない。
- 判断に迷う内容は `secretary/inbox/` に記録し、ユーザーの確認を仰ぐ。
- 新しい案件を把握したら、該当するサービス区分の案件一覧に行を追加する。
  サービス区分の判断に迷う場合は`その他/`に記録した上でsecretary/inboxに確認事項として残す。
