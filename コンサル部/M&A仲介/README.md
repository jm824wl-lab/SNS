# M&A仲介

## 概要

M&A仲介案件(買収・売却の紹介・仲介)を管理する。取引先(買い手候補の投資会社等)
ごとにサブフォルダを作り、その中で案件一覧を管理する。

## 現在管理中の取引先

- `BoldInvestment案件管理/` — 株式会社Bold Investment(大原正規様)との
  M&A案件ソーシング。詳細は同フォルダの`README.md`を参照。

## 運用ルール

- 新しい買い手候補・取引先との継続的なやり取りが始まったら、取引先ごとに
  サブフォルダ(`<取引先名>案件管理/`)を作成し、同様の構成(README.md・案件管理.csv、
  `取引先`列を含む)で管理する。
- 単発の案件で継続的な取引先管理が不要な場合は、`その他/`またはこのフォルダ直下の
  案件一覧で管理することも検討する。
- 作業ログは `コンサル部/logs/YYYY-MM-DD.md` に追記形式で記録する。
- 判断に迷う内容は `secretary/inbox/` に記録する。
