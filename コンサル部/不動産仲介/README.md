# 不動産仲介

## 概要

不動産売買・仲介案件を管理する。物件情報の紹介メール(各種不動産会社から多数受信)
のうち、実際に検討・対応が進んでいる案件をここで管理する。

## ファイル構成

- `案件一覧.csv` — 案件ごとの一覧。列: No, 物件名/案件名, 売主/買主, ステータス,
  紹介元(仲介会社等), 金額, 次のアクション, 備考

## 運用ルール

- 新しい案件(具体的に検討が進んだもの)を把握したら`案件一覧.csv`に行を追加する。
- 単なる物件紹介メール(日々多数受信)は、具体的な検討に進んだ段階で記録する。
  全件を自動的に記録はしない。
- ステータスが変わったら該当行を更新する(検討中/内見/申込/契約/決済/クローズ等)。
- 作業ログは `コンサル部/logs/YYYY-MM-DD.md` に追記形式で記録する。
- 判断に迷う内容は `secretary/inbox/` に記録する。

  具体的に進行中の案件を特定できていない。整理が必要であれば依頼いただきたい。
