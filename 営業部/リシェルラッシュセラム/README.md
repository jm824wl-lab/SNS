# リシェルラッシュセラム事業 管理

## 事業概要

2026年10月、株式会社サーキュレーション(橋本様)より譲り受けた事業(まつげ美容液
「リシェルラッシュセラム」の販売)。経済産業省の助成金受理対象事業のため、譲渡報告書
の提出等、行政手続き関連は別途 `総務部` で管理する(`総務部/logs/2026-10-20.md` 参照)。
本フォルダでは、事業譲り受け後の**日々の受注・発送・収支の運用管理**を行う。

## 管理体制

本フォルダで以下3点を一元管理する。

1. **受注管理**: `受注管理.csv` — 注文が入るたびに行を追加する。
2. **発送管理**: 受注管理.csv内の発送状況列で管理する(受注・発送は1件の注文に紐づくため
   同一ファイルで管理)。
3. **収支管理**: `収支管理.csv` — 売上の入金確定分、仕入・送料・広告費等の経費発生分を
   その都度記録する。

## ファイル構成

- `受注管理.csv` — 受注・発送の記録簿。列: 注文ID, 注文日, 顧客名, 連絡先, 商品名, 数量,
  単価, 商品小計, 送料, 合計金額, 支払方法, 入金状況, 入金日, 発送状況, 発送日, 配送業者,
  追跡番号, 備考
  - 2026-11-15時点、過去の個別受注データは入手できておらず空欄(ヘッダーのみ)。新規受注
    発生分からここに記録していく。
- `収支管理.csv` — 収支の記録簿。列: 日付, 区分(売上/販売管理費/人件費/仕入/送料/広告費/
  その他経費), 内容, 金額, 関連注文ID, 備考
  - 2026-11-15、ユーザー提供のスプレッドシート(旧運営元からの引継ぎ資料)より2022年
    ～2026年9月の売上・販管費・人件費の実績を転記済み(下記「過去の販売実績」参照)。
- `取引先一覧.csv` — 販売チャネル(卸先・サロン等)・製造委託先・印刷物委託先の連絡先一覧。
  同スプレッドシートの「取引先」シートより転記。
- `logs/` — 運用上の変更・月次振り返り等を `YYYY-MM-DD.md` 形式で記録(従来の秘書ログと
  同じ追記ルール)。

## 運用ルール

- 新規受注を把握したら `受注管理.csv` に行を追加する(既存行は削除しない)。
- 発送完了・入金確認など状況が変わった場合は、該当行の状況列(入金状況・入金日・
  発送状況・発送日等)を更新する。過去の注文自体の記録(注文日・商品・金額等)は
  後から書き換えない。
- 収支の発生(売上確定・仕入・経費等)はその都度 `収支管理.csv` に追記する。
- 月末等の節目で `logs/YYYY-MM-DD.md` に月次サマリー(受注件数・売上合計・主な経費等)
  を記録する。
- 判断に迷う事項(返品・返金対応、価格設定変更等)は `secretary/inbox/` に記録し、
  ユーザーの確認を仰ぐ。
- CSVの直接編集が難しい場合は、秘書に「リシェルラッシュセラムの受注を追加して」等と
  伝えれば、秘書が本フォルダのファイルを更新する。
