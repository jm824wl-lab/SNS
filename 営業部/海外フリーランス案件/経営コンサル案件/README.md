# 経営コンサル案件(海外フリーランス・短期)

## 概要

海外フリーランスサイト(Upwork等)で募集されている、短期(スポット)の経営・
ビジネスコンサルティング系案件を調査し、申込検討ができるように管理する。
日本語を活かせる案件に限定せず、広く経営コンサルタント(宮内様)として取り組める
短期案件を対象とする。

## ファイル構成

- `案件一覧.csv` — 調査で見つかった案件一覧。列: No, 案件名/カテゴリ, プラットフォーム,
  内容, 単発/継続, 報酬目安, 必要スキル・条件, URL, ステータス, 備考

## 運用ルール

- 新しい案件候補が見つかったら`案件一覧.csv`に行を追加する。
- ステータス(未検討/検討中/応募済み/見送り等)が変わったら該当行を更新する。
- 作業ログは `営業部/logs/YYYY-MM-DD.md` に追記形式で記録する。
- 判断に迷う内容は `secretary/inbox/` に記録する。

## ダッシュボード(ブラウザで見える案件管理)

https://claude.ai/artifact/9Fw2VW4sEEdmf9qz5Veu1h

画面上で各案件のステータス(未検討/検討中/応募済み/見送り)を編集・削除できる。
案件データの正本はダッシュボードの保存領域にあり、`案件一覧.csv`は2026-11-21
時点のスナップショット(以後の編集とは自動的に同期しない)。

## 未整備事項・留意点

- 2026-11-21時点、Web検索で確認できた実在の案件は9件(すべてUpwork)。
- Catalant(旧HourlyNerd)・Toptal・GLG等の専門家専用マッチング型プラットフォームは、
  企業が案件を掲示し登録エキスパートのダッシュボードに表示される仕組みのため、
  個別求人を外部から検索・確認することはできなかった。宮内様がこれらに登録する
  場合は、登録後にプラットフォーム上で案件を確認する形になる。
- No.1(Japan Market Entry & Business Development Consultant)は日本市場知見を
  求める案件であり、宮内様の強みを特に活かせる可能性がある。
- フリーランス案件は応募期限が短く、掲載URLはすぐに無効になる可能性が高い。
