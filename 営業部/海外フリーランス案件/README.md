# 海外フリーランス案件(日本語スポット案件)

## 概要

海外(日本国外)のフリーランス案件マッチングサイト(Upwork等)で募集されている、
日本語スキルを活かせる単発・スポット案件を調査し、申込検討ができるように管理する。

## ファイル構成

- `案件一覧.csv` — 調査で見つかった案件一覧。列: No, 案件名/カテゴリ, プラットフォーム,
  内容, 単発/継続, 報酬目安, 日本語要件, URL, ステータス, 備考

## 運用ルール

- 新しい案件候補が見つかったら`案件一覧.csv`に行を追加する。
- ステータス(未検討/検討中/応募済み/見送り等)が変わったら該当行を更新する。
- 作業ログは `営業部/logs/YYYY-MM-DD.md` に追記形式で記録する。
- 判断に迷う内容は `secretary/inbox/` に記録する。

## 未整備事項・留意点

- 2026-11-21時点、Web検索で確認できた実在の案件は8件(すべてUpwork)。PeoplePerHour・
  Freelancer.comは個別の募集中求人を確認できず(過去の終了済み募集か、カテゴリページ
  のみ)。
- フリーランス案件は応募期限が短く(数時間〜数日で締切・終了する場合が多い)、
  掲載URLはすぐに無効になる可能性が高い。本リストは2026-11-21時点のスナップショット
  であり、実際に応募する際は各URLで募集状況を再確認すること。
- 報酬が「不明」の案件は、応募ページ上で詳細を確認する必要がある。
