# Amazonブラックフライデー用 X投稿(犬の飼い主向け)

軸は「犬のいる暮らし」。リンクなしの準備投稿を先に出し、リンクつきはセール開始後に使います。
全投稿、Xの文字数上限(全角140字相当)に収まることを確認済みです。
`【】` は差し替え箇所で、差し替え後に上限を超えないよう注意してください。

## 準備投稿(リンクなし・〜セール開始前)

### 1. 消耗品の確認
```
ブラックフライデー前に、犬の消耗品でやっておくこと

・フードとペットシーツの残量を確認
・いつもの商品の今の価格をメモ
・ほしい物リストに入れる

普段の価格を知らないと、安いか判断できません。
#犬のいる暮らし
```

### 2. フードのまとめ買い
```
フードをまとめ買いする前に確認すること

・賞味期限
・開封後に食べ切れる量か
・保管場所があるか

大袋は割安でも、開封後に風味が落ちて食べなくなることがあります。食べ切れる量で選ぶほうが結局安く済みます。
```

### 3. 見守りカメラ
```
留守番用の見守りカメラで見ている点

・夜でも様子が分かるか
・通知が多すぎないか
・録画の保存に月額料金がかかるか

本体が安くても、月額料金で高くつくことがあります。
#犬のいる暮らし
```

### 4. 自動給餌器
```
自動給餌器を選ぶ前に確認すること

・いつものフードの粒の大きさに対応しているか
・停電時に電池で動くか
・容器を外して洗えるか

粒が合わないと詰まります。対応サイズは必ず確認を。
```

### 5. 質問(会話のきっかけ)
```
犬を飼っている方に質問です。

ブラックフライデーで買う予定のものはありますか？

うちはペットシーツのまとめ買いと、【検討中のもの】を見ています。参考にしたいので教えてください。
#犬のいる暮らし
```

## セール期間の投稿(リンクあり)

### 6. 公式発表の当日(リンクなし)
```
Amazonブラックフライデーの日程が発表されました。

先行セール：【日付】
本セール：【日付】

犬用品と、犬のいる家で役立つ家電は、開始後にこのアカウントでまとめます。
#犬のいる暮らし
```

### 7. 開始直後の速報
```
【PR】ブラックフライデー開始。犬のいる家向けの対象品

・【消耗品】：まとめ買い向き
・【家電】：【理由】
・【その他】：【理由】

価格は変動するのでリンク先で確認を。
【リンク】
```

### 8. 単品紹介
```
【PR】【商品名】がセール対象です。

【使っている場合は分かった点を1つ／未使用なら仕様で選んだ理由】
【向いている家庭】

【リンク】
```

### 9. 本・動画
```
【PR】セールの合間に。

【本または作品のタイトル】
【役に立った点・良かった点を1つ】

【Kindle版／レンタル】が対象です。
【リンク】
```

### 10. 最終日
```
【PR】ブラックフライデーは本日【時刻】まで。

犬の消耗品を買い足すなら今日が区切りです。今回の対象品を再掲します。
【リンク】
```

## 守ること

- リンクつき投稿は冒頭に【PR】を置く。
- 価格と割引率は本文に書かない(セール中に変わるため)。
- フードやサプリの効能を断定しない。「うちでは食いつきが良かった」など事実の範囲で書く。
- 使っていない商品を「使っている」と書かない。
- セール対象かどうかは、投稿直前に商品ページで確認する。
