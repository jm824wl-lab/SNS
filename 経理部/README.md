# 経理部

## 担当業務

- 入出金管理
- 経費精算

## 運用ルール

- 秘書がこのフォルダに直接作業内容を記録する。
- 作業ログは `logs/YYYY-MM-DD.md` に追記形式で記録する（同日ファイルがあれば追記）。
- 既存ファイルは上書きしない。
- 判断に迷う内容は `secretary/inbox/` に記録し、ユーザーの確認を仰ぐ。

## 入出金管理ツール

- 入出金・請求書の主なソースは INVOY ダッシュボード（https://www.invoy.jp/dashboard/）。
  経理部の入出金状況確認は、まずここを正とする（2026-08-27 ユーザー確認済み）。
- メールで届く支払い催促（UPSIDER、BlueBank、ビジネスエアポート等）は、INVOYの記録と
  突き合わせて未消込がないか確認し、`logs/YYYY-MM-DD.md` に確認結果を記録する。
