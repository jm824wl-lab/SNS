# 法務部

## 担当業務

- 契約関係書類の内容確認(リーガルチェック)
  - 契約書・規約・覚書等の条項確認、リスクの指摘
  - 不利な条項・曖昧な表現・抜け漏れの洗い出し
- 総務部(契約管理)とは役割を分担する
  - 総務部: 契約の締結・保管・更新管理などの事務管理
  - 法務部: 契約書類の「内容」そのものの確認・リーガルリスクの指摘

## 運用ルール

- 秘書がこのフォルダに直接作業内容を記録する。
- 契約書類の確認結果・指摘事項は `logs/YYYY-MM-DD.md` に追記形式で記録する(同日ファイルが
  あれば追記)。
- 既存ファイルは上書きしない。
- 重大なリーガルリスク(違約金・損害賠償条項、独占条項、自動更新条項など、ユーザーの
  意思確認が必要な事項)を発見した場合は `secretary/inbox/` に記録し、ユーザーの確認を
  仰ぐ。
- 法務部はあくまで一次チェックを行う。契約内容について最終的な法的判断が必要な場合は、
  弁護士等の専門家への確認をユーザーに促す(法務部が最終的な法的助言を行うものではない)。
