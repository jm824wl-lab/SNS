# 総勘定元帳 コスト分析

会計ソフトから出力した**総勘定元帳・仕訳帳**を取り込み、勘定科目ごとの金額を集計してコスト分析を行うWebアプリです。

> 🔒 ファイルはブラウザ内だけで処理し、サーバーには送信しません(バックエンド不要)。
> ブラウザに保存されるのは「科目設定」で変更した分類のみです。

## 主な機能

| 画面 | 内容 |
|---|---|
| サマリー | 売上高・費用合計・売上総利益・営業利益・経常利益、固定費/変動費の比率、限界利益率、損益分岐点売上高・安全余裕率。月次の費用推移(固変別/損益区分別)と売上高、費用の大きい科目上位10件、直近月が期間平均を30%以上上回った科目の自動検出 |
| 科目別集計 | 期間合計・費用構成比・売上高比・月平均・最新月・前月比・平均比・件数。並べ替え・検索・CSV出力 |
| 月次推移 | 科目×月のピボット表(区分ごとの小計・費用合計)、最大8科目の推移グラフ、CSV出力 |
| 明細分析 | 科目別の月次グラフ、取引先/部門/相手勘定科目/摘要別の内訳、明細一覧(検索・CSV出力) |
| 科目設定 | 損益区分(売上・売上原価・販管費・営業外・特別損益・法人税等・貸借対照表)と固定費/変動費の変更 |

期間(開始月〜終了月)と部門で全画面を絞り込めます。

## 対応している入力形式

- **ファイル**: CSV / TSV(Shift_JIS・UTF-8・BOM付きを自動判定)、Excel `.xlsx`(複数シート可)。旧形式 `.xls` は `.xlsx` か CSV に保存し直してください。
- **元帳形式**(1行=1科目側の明細)
  - 「勘定科目」列がある形式
  - 勘定科目列が無く、科目ごとに見出し行(例: `【7100】旅費交通費`、`勘定科目: 消耗品費`)で区切られている形式
  - Excel で科目ごとにシートが分かれている形式(シート名を科目名として使用)
- **仕訳帳形式**(`借方勘定科目`・`貸方勘定科目` 列がある形式)は、1仕訳を借方側・貸方側の2明細に展開して元帳に変換します。
- 見出し行は先頭30行から自動検出し、列(日付・勘定科目・相手勘定科目・借方/貸方金額・取引先・部門・摘要)を自動で割り当てます。取込後に「列の割り当てを確認・変更」で修正できます。
- 前期繰越・月計・合計・累計などの集計行は自動で除外します。
- 日付は `2025/4/1`、`2025年4月1日`、`20250401`、和暦(`R7/4/1`・`令和7年4月1日`)、Excelシリアル値に対応。`4/1` のように年が無い場合は、画面の「期首年・期首月」から年を補完します。
- 金額は桁区切り・`¥`・`円`・全角数字・マイナス表記(`△` `▲` `-` `()`)に対応。

## 集計ルール

- 費用・資産科目は「借方 − 貸方」、収益科目(売上・営業外収益・特別利益)は「貸方 − 借方」で集計します。
- 損益区分と固定費/変動費は科目名から自動判定します(固変分解は中小企業庁方式を簡略化した目安)。自社の実態に合わせて「科目設定」で変更してください。
- 損益分岐点売上高 = 固定費 ÷ 限界利益率(限界利益率 = (売上高 − 変動費) ÷ 売上高)。営業外費用の固定費を含み、特別損失・営業外収益は含めません。

## 開発

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 解析・分類・集計ロジックのテスト(vitest)
npm run build    # dist/ に静的ファイルを出力(任意の静的ホスティングで公開可能)
npm run build:artifact  # JS・CSSを埋め込んだ1ファイル版 dist-artifact/cost-analysis.html を出力
```

1ファイル版は claude.ai の Artifact として公開しています(CSV保存は Artifact の downloads 機能を使用)。
表の「コピー / CSV出力」ボタンは、Excel に貼り付けられる形式でクリップボードにコピーし、CSVファイルの保存も行います。

初回表示時と「サンプルデータで試す」ボタンで、架空の卸売業1年分(2025年4月〜2026年3月)の総勘定元帳を読み込めます。自社データを取り込むとサンプルは置き換わります。

### 構成

```
src/
  lib/            UI から独立したロジック(テスト対象)
    csv.ts        文字コード判定・CSV解析/出力
    parse.ts      見出し検出・列の自動割り当て・元帳/仕訳帳の正規化
    classify.ts   科目の損益区分・固変区分の推定と保存
    aggregate.ts  科目別・月別集計、損益/損益分岐点、増減比較、内訳
    load.ts       CSV/Excel ファイル読込
    sample.ts     デモ用サンプル元帳
  components/     画面(取込・サマリー・科目別集計・月次推移・明細分析・科目設定)
```

Excel 読込には `read-excel-file` を使用しています(npm 版 `xlsx`(SheetJS 0.18.5)は既知の脆弱性があるため不採用)。
