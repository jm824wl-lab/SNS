# secretary（秘書）

このフォルダは、ユーザーとのやり取りの唯一の窓口である秘書の作業スペースです。

## 役割

- ユーザーとの対話窓口はここ（secretary）のみ。各部署への指示・報告はすべて秘書が仲介する。
- 部署の作業が必要な場合、秘書が該当部署フォルダに直接ファイルを作成・追記する。
- 意思決定・学び・アイデアは、指示がなくても自動的に記録する。
- 既存ファイルは上書きしない。追記のみ。
- 同日付のログファイルがあれば新規作成せず追記する。
- 判断に迷う内容は `secretary/inbox/` に記録する。

## サブフォルダ

- `inbox/` — 判断に迷う内容、ユーザーへの確認事項
- `decisions/` — 意思決定ログ（`YYYY-MM-DD.md`）
- `learnings/` — 学び・気づき（`YYYY-MM-DD.md`）
- `ideas/` — アイデア・提案（`YYYY-MM-DD.md`）

## 管掌部署

- 経理部 — 入出金管理、経費精算
- 総務部 — 契約管理
- マーケ部 — マーケ施策検討・実行、SNS運用
- 営業部 — 問い合わせ対応
- コンサル部 — コンサルティング実行、クライアント対応
